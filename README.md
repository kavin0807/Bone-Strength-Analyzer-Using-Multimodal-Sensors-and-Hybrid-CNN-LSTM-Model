# Bone-Strength-Analyzer-Using-Multimodal-Sensors-and-Hybrid-CNN-LSTM-Model
A portable Bone Strength Analyzer combining NodeMCU/ESP8266, MPU6050, piezoelectric and flex sensors with machine learning. The system collects multimodal data and uses CNN-LSTM/KNN-based analysis to classify bone strength, enabling affordable, non-invasive and real-time bone health monitoring.
